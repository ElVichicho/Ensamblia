# Reportar un problema de seguridad

Usa la opción **Report a vulnerability** en la pestaña Security de GitHub si está habilitada, o contacta al mantenedor por privado desde su perfil. Si no encuentras un canal privado, abre un issue solicitándolo sin publicar detalles del fallo.

Incluye la ruta afectada, el resultado esperado y los pasos para reproducirlo con datos ficticios. Omite claves, tokens y datos personales. Reporta especialmente exposición de credenciales, acceso público a la cuota de IA o alteración de precios y selecciones del servidor.
